# Quick Start Guide for ThumbGen 🚀

**ThumbGen - Make YouTube Easy with ThumbGen**

---

## ⚡ 5-Minute Setup

### 1. Install Node.js
Ensure Node.js 16+ is installed ([nodejs.org](https://nodejs.org/)).

### 2. Navigate to Project
```bash
cd thumbgen
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start Development Server
```bash
npm run dev
```

### 5. Open in Browser
Visit **[http://localhost:3000](http://localhost:3000)** in your browser! 🎉

---

## 📝 Usage Guide

### 🎨 Option 1: Image Upload & AI Thumbnail Generator
1. Drag & drop or click to upload an image.
2. 5 thumbnail variations are generated automatically.
3. Edit title text, color, background box, and font size in real time.
4. Click **Download PNG** to export YouTube 1280x720 thumbnail.

### 📹 Option 2: Video Frame Extractor
1. Upload a video file or pick a built-in sample video.
2. Extracted 10 keyframes appear automatically.
3. Click any frame to instantly turn it into a thumbnail design.

### ⬇️ Option 3: Download Video from URL
1. Paste direct MP4/WebM links or public Google Drive / Dropbox / OneDrive share links.
2. Click **Download Video** to stream and inspect metadata.

### 🎬 Option 4: Create Short Videos (Reels / TikTok / Shorts)
1. Upload an MP4/WebM video file.
2. Choose custom duration in seconds (e.g. 5s to 180s) or click quick presets (**15s**, **30s**, **45s**, **60s**).
3. Click **Generate All Short Videos with Voice**.
4. Preview clips in **Original HD (0 Lag)** mode or download ready `.webm` short videos!
